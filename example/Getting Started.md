# Fancy Charts — Example Vault

This vault is used for local development and testing of the Fancy Charts plugin.

To set up:
1. Run `npm run build` from the repo root
2. Run `bash bash/local-deploy.sh` to deploy the plugin here
3. Open this folder as an Obsidian vault
4. Enable **Fancy Charts** in Settings → Community Plugins

Chart examples will be added here as units are completed.
